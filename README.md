# Bean Root

welcome to bean root a simple game about planting plants that protect your 
main bean stalk from mobs!

The game is easy to play!

* Click play
* plant beans
* kill mobs to earn cash
* plant more beans
* merge extra beans into the main beanstalk to win the game

## Controlls

* w a s s -> 4 directional movement
* e to interact
